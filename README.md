# BT-J2ME

Лёгкая нативная «игровая консоль» для J2ME-игр на Linux: пиксельная полка
с коробками игр, интерфейс без надписей — только иконки, всё на весь экран
любого размера и ориентации, управление с клавиатуры или Xbox-геймпада,
без Java на компьютере. Пишется на C99, чтобы работать на
старых и слабых машинах любой разрядности (i386, x86_64, ARM, MIPS).
На той же полке живут картриджи NES / Денди и диски PlayStation.

Концепт и дорожная карта: [docs/CONCEPT.md](docs/CONCEPT.md).

> Статус: своя Java-машина запускает настоящие J2ME-игры. Проверено на четырёх
> свободных играх (Reversi, Tetris, Freecell, Sudoku) и на коммерческом
> симуляторе питомца «Мяусим» (Dynamic Pixels, 450 КБ): меню, игровой процесс,
> сохранения, музыка и звуки.

### Звук

Свой микшер и синтезатор, без внешних библиотек: MIDI (простой «телефонный»
синтезатор по семействам General MIDI с барабанами), WAV (PCM, IMA ADPCM,
A-law, μ-law), Sun AU, тоновые последовательности JSR-135, `Manager.playTone`
и Nokia `Sound` (тоны и рингтоны Smart Messaging). AMR и MP3 не декодируются —
такие плееры «играют» тишину. Звуковое устройство открывается при первом звуке.

```sh
./bt-j2me run игра.jar --mute                 # без звука
BT_AUDIO_DUMP=звук.wav ./bt-j2me run игра.jar # записать весь звук игры в файл
./bt-j2me audio-render theme.mid theme.wav    # сыграть звук из JAR в WAV
```

Замеры (Tetris в окне 800×600, программная отрисовка): процессор ~1%,
память всей программы ~13 МБ. Бинарник после `make strip` — около 2 МБ: ~0,5 МБ
занимают Java-машина, библиотека классов, шрифты и NES, остальное — ядро PlayStation.

## Скачать

Готовые сборки лежат в [Releases](https://github.com/FLEXIY0/BT-J2ME/releases/latest):
`bt-j2me.exe` (Windows), `bt-j2me.apk` (Android), `bt-j2me-linux-x86_64.tar.gz` (Linux).
Их собирает GitHub Actions (`.github/workflows/build.yml`) после каждого изменения в основной
ветке: выпуск получает номер `0.1.<номер сборки>`, APK подписан одним и тем же ключом и
ставится поверх прошлой версии с сохранениями. Номер версии — `bt-j2me --version`.

**Обновление само.** При запуске полка спрашивает GitHub, нет ли выпуска новее, и
предлагает обновиться: ✓ — скачать, ✕ — не сейчас (спросит в следующий раз). На Windows
и Linux новый файл встаёт на место старого и программа перезапускается; на Android
открывается системная установка APK (один раз нужно разрешить «установку из этого
источника»). Скачивается только файл из выпусков этого репозитория, размер сверяется.
Отключить проверку: `BT_NO_UPDATE=1`. Сборки без номера (`0.1.0-dev`) не проверяют.

## Сборка

Нужны C-компилятор, `make`, `zlib` и `SDL2` (dev-пакеты). Java для сборки
не нужна: библиотека классов уже лежит в `src/rt_jar.h`.

```sh
sudo apt install build-essential zlib1g-dev libsdl2-dev   # Debian/Ubuntu
make            # SDL2, оптимизация по размеру
make test       # тесты; Java-тесты машины и MIDP — если есть javac, PNG — если есть Pillow
make strip      # уменьшить бинарник

make BACKEND=null                        # без графики
make CROSS=arm-linux-gnueabihf-          # кросс-сборка
make CFLAGS="-O2 -march=pentium2"        # под конкретный старый процессор
```

### Windows

`bt-j2me.exe` — один файл без DLL (SDL2 и zlib вшиты), собирается из Linux:

```sh
sudo apt install gcc-mingw-w64-x86-64 libz-mingw-w64-dev
sh tools/build-windows.sh    # dist/bt-j2me.exe и dist/bt-j2me-console.exe (с логами)
```

На Windows полка — папка `games` рядом с `bt-j2me.exe`, настройки и сохранения —
в `%APPDATA%\bt-j2me`. Добавить игру: положить JAR в `games`, перетащить его на
`bt-j2me.exe` или прямо в открытое окно — файл (вместе с JAD рядом) скопируется
на полку, и она откроется на нём. Имена файлов и папок с русскими буквами поддерживаются.

### Android

APK для Android 4.1 Jelly Bean и новее (armeabi-v7a, x86; на 64-битных телефонах — arm64-v8a,
x86_64) собирается из Linux. 4.1 — нижний предел: SDL2 нужны EGL и OpenGL ES 2.0:

```sh
# нужны JDK 17+, Android SDK (platforms;android-34, build-tools;34.0.0, cmake;3.22.1)
# и NDK 23.2.8568313 (r23c — последний, что собирает под 4.1); ANDROID_HOME — путь к SDK
sh tools/build-android.sh    # dist/bt-j2me.apk
```

Игры добавляются плиткой «+» на полке (системный выбор файлов) или через
«Открыть с помощью → BT-J2ME» для `.jar`/`.jad` из файлового менеджера, браузера
или мессенджера. Они копируются в `Android/data/ru.flexiy0.btj2me/files/games`.
Кнопка «Назад» выходит из игры на полку. Если в игре поле ввода, сама появляется
клавиатура Android.

## Использование

```sh
sh demo/get-demo-games.sh        # скачать 4 свободные GPL-игры на полку
./bt-j2me                        # меню-полка (~/.local/share/bt-j2me/games)
./bt-j2me ~/игры/j2me            # полка из другой папки
./bt-j2me run игра.jar           # запустить игру сразу, без меню
./bt-j2me run "Игра (USA).cue"   # диск PlayStation (.cue, .bin, .iso, .img, .pbp)
./bt-j2me info игра.jar          # название, MIDlet-ы, проверка всех классов
./bt-j2me display-test           # проверить экран и клавиши
```

Опции: `--windowed` — в окне, `--gpu` — рисовать через OpenGL (по умолчанию
программно: так на порядок меньше памяти и надёжнее на старых ПК),
`--smooth` / `--sharp` — дробный или только целый масштаб игр.

### Интерфейс

Три вкладки внизу (иконки, без подписей):

- **Полка** (геймпад) — коробки игр в 3D: центральная крупная, соседние
  повёрнуты к ней торцом; название и издатель под коробкой, `‹ ›` по бокам,
  счётчик сверху. При запуске из коробки выезжает крутящийся диск.
- **Библиотека** (список) — все игры сеткой, выбор переносит на полку.
- **Настройки** (шестерёнка) — три переключателя: ☀/☾ тема, «шахматка» —
  крупный/мелкий пиксель интерфейса, «лесенка» — только целый масштаб игр.
  Сохраняются в `~/.config/bt-j2me/settings`.

Интерфейс рисуется в маленьком разрешении (короткая сторона ≈190 пикселей,
в режиме мелкого пикселя ≈270) и увеличивается целым множителем — поэтому
он чёткий и занимает весь экран без полей на любом мониторе, ноутбуке,
ЭЛТ или вертикальном экране.

### Обложки

**Кадр из игры.** При первом нажатии в игре (не раньше чем через 2,5 с) лаунчер
запоминает экран: почти всегда это заставка «нажмите, чтобы играть». Пока своей
обложки нет, на коробке будет этот кадр. Скриншоты можно делать и самому: **F12**
на ПК или кнопка с фотоаппаратом на телефоне. Значок картинки слева вверху на
полке (или клавиша 0 / View на геймпаде) открывает выбор обложки: листаете
снимки ◀ ▶, двигаете рамку пальцем или клавишами 2/4/6/8, меняете её размер
кнопками − и +, затем ✓. Кадр сохраняется в `covers/<игра>.png`, 🗑 возвращает
обложку по умолчанию. Скриншоты лежат в `~/.local/share/bt-j2me/shots/<игра>/`.


Обложка ищется так:

1. `<папка>/<имя-jar>.png`
2. `<папка>/covers/<имя-jar>.png`
3. иначе рисуется автоматически: цвет по названию, значок-овал и
   крупная иконка игры из JAR (или диск, если иконки нет) — без надписей.

Подойдёт любая PNG; лучше вертикальная примерно 3:4 (как коробка), иначе
лишнее по краям обрезается. Уменьшается с усреднением, поэтому сканы
настоящих обложек тоже смотрятся аккуратно.

### Управление

| Действие               | Клавиатура            | Xbox-геймпад            |
|------------------------|-----------------------|-------------------------|
| Листать / выбирать     | стрелки (WASD, 2468)  | крестовина / левый стик |
| Запустить / включить   | Enter, пробел, 5      | A                       |
| Соседняя вкладка       | * / # (numpad / и *)  | LB / RB                 |
| Перейти к вкладкам     | ↓ на полке            | ↓                       |
| Сбросить игру          | Delete, 3             | Y                       |
| Назад / выход          | Esc                   | кнопка Xbox             |
| Полный экран / окно    | F11, Alt+Enter        |                         |

Мышь тоже работает: клик по коробке, стрелкам, вкладкам, переключателям; на полке
рисуется рука-указатель, её же водит левый стик геймпада (A — клик).

**Сброс игры.** Корзина слева вверху на полке (Delete или Y на геймпаде) стирает
сохранения выбранной игры — рекорды, прогресс, настройки внутри игры, — и она
начинается как в первый раз. Окно спрашивает подтверждение: точки — сколько файлов
сохранений найдено, ✕ — отмена (выбрана сразу), ✓ — стереть. Обложка и скриншоты
остаются.

**Esc** (на геймпаде — **View**, кнопка с двумя рамками) в игре — меню паузы: полный экран или окно, масштаб
(чёткий, по размеру, авто, растянуть во весь экран), фильтр картинки, размер экрана
и широкий экран для этой игры, звук, снимок экрана, выход на полку. Выбор запоминается.

**Экран игры.** Размер берётся из манифеста, а если его там нет — из самой игры: многие
сборки «под один телефон» зашивают его в свой Canvas (The Sims 3 — 240×400). Если низ
или край всё равно уходят за кадр, выберите размер вручную в меню паузы: «Экран игры»
(128×160 … 480×640); после закрытия меню игра перезапустится с ним.

**Язык.** Игры узнают язык системы (`microedition.locale`, например `ru-RU`) и, если в них
есть русский, включают его сами. Если в JAR русского нет (как в английской The Sims 3),
нужна русская версия игры. Подменить язык: `BT_LOCALE=en-US`.

Фильтры (◀ ▶ на пункте «Фильтр»): **ЭЛТ** — строки кинескопа, мягкие края и
затемнённые углы; **грубые пиксели** — квадраты 2×2 и 8 оттенков на канал;
**Game Boy** — четыре зелёных тона с узором смешения и сеткой экрана; **ЖК-экран** —
сетка между пикселями, как у телефона; **ч/б** и **сепия**. Строки и сетка видны
при увеличении от 2×; снимки экрана сохраняются без фильтра.

В играх с полями ввода (имя в таблице рекордов) буквы печатаются с
клавиатуры, Backspace стирает. Если игра рисует поле сама (имя котёнка в Мяусим),
начните печатать (две буквы подряд) — включится режим букв (вверху подсказка; вручную — **Tab**):
буквы, кириллица и пробел уходят в игру мультитапом, как на кнопочном телефоне,
а W/A/S/D перестают быть стрелками. Enter или стрелки — выйти. Язык букв
(латиница/кириллица) переключает сама игра, обычно клавишей # или *.

С геймпада текст набирается экранной клавиатурой: **нажмите на стик** (L3/R3).
Крестовина или стик — выбор, A — ввести, B — стереть, X — пробел, Y — заглавные,
LB/RB — русские/латинские, Start — готово.

В игре: стрелки/WASD и крестовина/стик — джойстик телефона; Enter и **A** —
«огонь»; F1/Q и **Start** — левая софт-клавиша; F2/E и **B** — правая софт-клавиша
(«назад»); цифры — цифры, а на геймпаде **X** = 1, **Y** = 3, **LB** = *, **RB** = #,
**View** — меню паузы (цифра 0 — на экранной клавиатуре). Геймпады подключаются
на лету: на полке сверху и в игре (сбоку от картинки или полосой внизу) появляются
подсказки, какая кнопка что делает. **LB+RB** вместе прячут и возвращают их.

**Залипание стрелок** (меню паузы на ПК, кнопка «→|» в редакторе сенсорных кнопок) —
для игр вроде «Кошек-мышек», где поворот срабатывает, только пока стрелка зажата:
отпущенное направление держится ещё 0,45 с, новое сразу сменяет его.

### Картриджи NES / Денди

Рядом с JAR-ами на полку можно класть образы `.nes` (iNES и NES 2.0) — они запускаются
встроенным эмулятором, без отдельных ядер и программ. Процессор 6502 считается по тактам
шины (тест nestest сходится на всех 8991 командах, blargg `all_instrs` проходит целиком),
видеочип — по точкам (вспышка спрайта 0, растровые эффекты, счётчики строк), звук — все
пять каналов APU и звук Konami VRC6.

Поддержанные мапперы: 0 (NROM), 1 (MMC1), 2 (UxROM), 3 (CNROM), 4 (MMC3), 5 (MMC5, без
звука), 7 (AxROM), 9/10 (MMC2/MMC4), 11, 15 (пиратские «100 в 1»), 21–26 (Konami VRC2/4/6),
34, 66, 69 (Sunsoft FME-7, без звука 5B), 71 (Camerica), 79, 87, 113, 140, 180, 206, 232 —
это почти все популярные игры: Mario, Contra, Чип и Дейл, Утиные истории, Черепашки,
Battletoads, Мега Мен, Zelda, Castlevania. Регион — по заголовку или имени файла:
«(E)», «(Europe)» — PAL (50 кадров), иначе NTSC.

| Кнопка NES | Клавиатура             | Xbox-геймпад |
|------------|------------------------|--------------|
| A          | X, J, пробел           | A или Y      |
| B          | Z, K                   | B или X      |
| Start      | Enter                  | Start        |
| Select     | Shift, Tab, Backspace  | LB / RB      |

На Android работают те же сенсорные кнопки, что и для J2ME: 5 и огонь — A, правая софт-клавиша
и 1 — B, левая софт — Start, # и 0 — Select. В меню паузы у картриджа — «Сохранить игру»,
«Загрузить игру» (быстрые сохранения) и «Сброс»; фильтры (ЭЛТ, Game Boy…) работают и здесь.
Память картриджа с батарейкой (Zelda и др.) сохраняется сама; «сброс игры» на полке стирает и её.

### Диски PlayStation

Рядом с играми на полку можно класть диски PS1: `.cue` с дорожками `.bin` (и музыкой
CD-DA), одиночные `.bin`, `.iso`, `.img` и `.pbp` (образы из PSN, сжатые). Название —
из имени файла без пометок «(USA)», «[!]»; на коробке — диск. Дорожки, которые называет
`.cue`, отдельными коробками не показываются. Перетаскивание на окно и «Открыть с помощью»
переносят на полку `.cue` вместе с его дорожками, а к `.bin` — одноимённый `.cue`, если
он лежит рядом. Образ диска весит сотни мегабайт, так что копирование занимает время.

Внутри — ядро [PCSX-ReARMed](https://github.com/libretro/pcsx_rearmed) (GPL-2,
`third_party/pcsx_rearmed`). Его делали для слабых ARM-машин: на телефонах (ARMv7 и
ARM64) игры идут через динамический перекомпилятор процессора R3000A, графику рисует
рендер на NEON. На ПК (x86) работают интерпретатор и тот же рендер на SSE, скорости там
хватает с запасом. Звук SPU, голос и музыка XA, дорожки CD-DA, ролики MDEC, карты памяти
тоже эмулируются. Если машина не успевает, ядро пропускает отрисовку отдельных кадров, но
не звук: так игра реже замедляется, а звук не рвётся. Экран всегда показывается 4:3, как
на телевизоре, в любом разрешении игры (256…640 точек в ширину). Фильтры из меню паузы
(ЭЛТ, «грубые пиксели» и др.) работают и здесь.

**BIOS.** Лучше всего положить настоящий BIOS приставки (`scph1001.bin`, `scph5501.bin`,
`scph7502.bin` и т. п., ровно 512 КБ) в папку `bios` рядом с играми или прямо к играм; на
Android его можно добавить через «Добавить игры», он сам ляжет в `bios`. Без BIOS ядро
запускает встроенный HLE-BIOS: большинство игр работает и с ним, но совместимость ниже,
и некоторые игры показывают чёрный экран или не видят карту памяти.

| DualShock | Клавиатура            | Xbox-геймпад         |
|-----------|-----------------------|----------------------|
| ×         | K, Z, пробел          | A                    |
| ○         | L, X                  | B                    |
| □         | J, C                  | X                    |
| △         | I, V                  | Y                    |
| L1 / R1   | Q / E                 | LB / RB              |
| L2 / R2   | 1 / 3                 | LT / RT (курки)      |
| L3 / R3   | F / G                 | нажатие стиков       |
| Start     | Enter                 | Start                |
| Select    | Shift, Tab, Backspace | View                 |
| крестовина| стрелки, WASD         | крестовина, левый стик |

Меню паузы — Esc, на геймпаде View и Start вместе (или кнопка Xbox): View у PS1 занята
под Select. В меню — «Сохранить игру», «Загрузить игру» (быстрые сохранения) и «Сброс».
Подсказки геймпада прячутся в меню («Подсказки геймпада»): LB+RB у PS1 — это L1+R1 в игре.
Пульт подключён как обычный цифровой (SCPH-1080), с ним работают почти все игры; игры,
которым обязательно нужен аналоговый режим DualShock, пока не поддерживаются.

На телефоне у PS1 свои сенсорные кнопки: слева — крестовина, справа — ромб △○×□ своих
цветов, сверху — L1/L2 и R1/R2, внизу — Select и Start. В альбомной ориентации они по
бокам от картинки, в портретной — под ней. Как и у J2ME-игр, в редакторе (⚙) кнопки можно
двигать, менять размер, убирать и добавлять (в том числе L3/R3), раскладка запоминается
для каждой игры.

Карта памяти (`pcsx-card1.mcd`, 128 КБ, формат совместим с другими эмуляторами) лежит в
папке сохранений игры и пишется сразу, как только игра сохраняется. Быстрое сохранение —
там же, в `state.sav`. «Сброс игры» на полке стирает и их.

Не поддерживаются: образы `.chd`, многодисковые наборы `.m3u` (диск меняется только через
выход на полку), световые пистолеты и мышь. На Android «Открыть с помощью» для `.cue` из
другого приложения передаёт только сам `.cue`, без дорожек. Такие диски добавляйте через
«Добавить игры», выбрав `.cue` и `.bin` вместе.

### Сенсорное управление (Android, на ПК — `--touch`)

Картинка игры в портрете стоит сверху, кнопки — под ней, в альбоме — по бокам:

- слева **плавающий стик**, как L3 у геймпада: он появляется там, куда поставили
  палец, а если увести палец дальше, центр едет следом. Можно выбрать 8 направлений
  или только 4 (так удобнее для старых игр и меню);
- справа квадратная кнопка **огонь** (центр крестовины, «5»), сверху две
  **софт-клавиши**;
- **⌨** выдвигает цифровую панель 1–9, *, 0, #;
- **⚙** открывает редактор. В нём любую клавишу телефона (стрелки, цифры, *, #, C,
  софт-клавиши, стик, панель) можно закрепить кнопкой поверх игры или убрать,
  перетащить пальцем, изменить её размер и общую прозрачность. Раскладка
  запоминается **для каждой игры отдельно**, своя для портрета и альбома.

Пока открыта панель ⌨, стик и «огонь» спрятаны: остаются только софт-клавиши,
⚙ и ⌨. Панель бывает двух видов:

- **цифры** 1–9, *, 0, #;
- **клавиатура** (русская и латинская). В поля ввода (TextBox) буквы уходят напрямую.
  В играх, которые сами рисуют поле имени и ждут ввода мультитапом, буква
  превращается в нажатия цифр, как на кнопочном телефоне: «р» — это 7 трижды.

В редакторе есть переключатель **экрана игры**: как задумано (240×320) или под
форму телефона. Во втором режиме игра получает экран той же ширины, но выше
(в портрете) или 16:9 (в альбоме), а строки вида `scr_width=240` в её конфиге
подменяются на лету. Игры, которые подстраиваются под размер экрана, например
«Мяусим», растягиваются без искажений. Игра при этом перезапускается.

Касание самой картинки передаётся игре как касание экрана. Нажатия дают короткий
отклик вибрацией, а `Display.vibrate()` из игр включает настоящую вибрацию.

## Java-машина

Своя, на C, без JRE: CLDC 1.1 (`java.lang`, `java.util`, `java.io`) и MIDP 2.0.

| Что | Состояние |
|---|---|
| Байткод | все опкоды Java 1.0–8 (кроме `invokedynamic`), исключения, `synchronized`, `jsr/ret` |
| Потоки | «зелёные» в одном системном потоке: `Thread`, `wait/notify`, `sleep`, `Timer` |
| Память | сборщик mark&sweep, куча до 48 МБ |
| `lcdui` | `Canvas`, `Graphics` (всё рисование, повороты картинок, пропорциональные шрифты с кириллицей), `Image` (PNG), `Form`, `List`, `Alert`, `TextBox`, `TextField`, `ChoiceGroup`, `Gauge`, команды и софт-клавиши с меню |
| `lcdui.game` | `GameCanvas`, `Sprite` (кадры, повороты, столкновения), `TiledLayer`, `LayerManager` |
| `rms` | `RecordStore` с перебором, фильтрами, сортировкой; файлы в `~/.local/share/bt-j2me/rms/<игра>/` |
| Свойства | `getAppProperty` читает JAD рядом с JAR, затем манифест |
| Nokia UI | `FullCanvas`, `DirectUtils`, `DirectGraphics`, `DeviceControl` |
| Звук (MMAPI, Nokia Sound) | MIDI, WAV, AU, тоны, OTT |
| 3D (M3G, JSR-184) | только 2D-часть: `Sprite3D`, `Image2D`, `Background`, `Camera`, `World`/`Group`, смешивание `CompositingMode` (затемнения и спрайты, как в The Sims 3); сеток `Mesh` и загрузчика `.m3g` нет |
| SMS (JSR-120) | эмуляция оплаты: `sms://` и `platformRequest("sms:…")` «уходят» успешно, ничего не отправляя, — покупки в старых играх проходят |
| Bluetooth (JSR-82), сеть | заглушки: игра узнаёт «недоступно» и показывает свою ошибку |
| M3G / Mascot Capsule (3D) | нет |

Экран игры — 240×320 или размер из `Nokia-MIDlet-Original-Display-Size`.
Нажатие клавиши доходит до игры не короче 100 мс: многие игры опрашивают
клавиши раз в кадр и иначе не заметили бы быстрый тап.
Если игра не запустилась, лаунчер покажет красный крест, а причину — в терминале;
`BT_J2ME_TRACE=1` печатает каждое брошенное в игре исключение.

Библиотека классов — Java-исходники в `runtime/`; после правок пересоберите её
`tools/build-rt.sh` (нужен JDK), получится новый `src/rt_jar.h`.
