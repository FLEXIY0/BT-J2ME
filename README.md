# BT-J2ME

Лёгкая нативная «игровая консоль» для J2ME-игр на Linux: пиксельная полка
с коробками игр, интерфейс без надписей — только иконки, всё на весь экран
любого размера и ориентации, управление с клавиатуры или Xbox-геймпада,
без Java на компьютере. Пишется на C99, чтобы работать на
старых и слабых машинах любой разрядности (i386, x86_64, ARM, MIPS).

Концепт и дорожная карта: [docs/CONCEPT.md](docs/CONCEPT.md).

> Статус: своя Java-машина запускает настоящие J2ME-игры. Проверено на четырёх
> свободных играх (Reversi, Tetris, Freecell, Sudoku) и на коммерческом
> симуляторе питомца «Мяусим» (Dynamic Pixels, 450 КБ): меню, игровой процесс,
> сохранения, музыка и звуки.

### Звук

Свой микшер и синтезатор, без внешних библиотек: MIDI (простой «телефонный»
синтезатор по семействам General MIDI с барабанами), WAV (PCM, IMA ADPCM,
A-law, μ-law), Sun AU, тоновые последовательности JSR-135, `Manager.playTone`
и Nokia `Sound` (тоны и рингтоны Smart Messaging). AMR и MP3 не декодируются —
такие плееры «играют» тишину. Звуковое устройство открывается при первом звуке.

```sh
./bt-j2me run игра.jar --mute                 # без звука
BT_AUDIO_DUMP=звук.wav ./bt-j2me run игра.jar # записать весь звук игры в файл
./bt-j2me audio-render theme.mid theme.wav    # сыграть звук из JAR в WAV
```

Замеры (Tetris в окне 800×600, программная отрисовка): процессор ~1%,
память всей программы ~13 МБ, бинарник после `make strip` ~310 КБ —
вместе со встроенной библиотекой классов и шрифтами.

## Сборка

Нужны C-компилятор, `make`, `zlib` и `SDL2` (dev-пакеты). Java для сборки
не нужна: библиотека классов уже лежит в `src/rt_jar.h`.

```sh
sudo apt install build-essential zlib1g-dev libsdl2-dev   # Debian/Ubuntu
make            # SDL2, оптимизация по размеру
make test       # тесты; Java-тесты машины и MIDP — если есть javac, PNG — если есть Pillow
make strip      # уменьшить бинарник

make BACKEND=null                        # без графики
make CROSS=arm-linux-gnueabihf-          # кросс-сборка
make CFLAGS="-O2 -march=pentium2"        # под конкретный старый процессор
```

### Windows

`bt-j2me.exe` — один файл без DLL (SDL2 и zlib вшиты), собирается из Linux:

```sh
sudo apt install gcc-mingw-w64-x86-64 libz-mingw-w64-dev
sh tools/build-windows.sh    # dist/bt-j2me.exe и dist/bt-j2me-console.exe (с логами)
```

На Windows полка — папка `games` рядом с `bt-j2me.exe`, настройки и сохранения —
в `%APPDATA%\bt-j2me`. Имена файлов и папок с русскими буквами поддерживаются.

### Android

APK для Android 4.1 Jelly Bean и новее (armeabi-v7a, x86; на 64-битных телефонах — arm64-v8a,
x86_64) собирается из Linux. 4.1 — нижний предел: SDL2 нужны EGL и OpenGL ES 2.0:

```sh
# нужны JDK 17+, Android SDK (platforms;android-34, build-tools;34.0.0, cmake;3.22.1)
# и NDK 23.2.8568313 (r23c — последний, что собирает под 4.1); ANDROID_HOME — путь к SDK
sh tools/build-android.sh    # dist/bt-j2me.apk
```

Игры добавляются плиткой «+» на полке (системный выбор файлов) или через
«Открыть с помощью → BT-J2ME» для `.jar`/`.jad` из файлового менеджера, браузера
или мессенджера. Они копируются в `Android/data/ru.flexiy0.btj2me/files/games`.
Кнопка «Назад» выходит из игры на полку. Если в игре поле ввода, сама появляется
клавиатура Android.

## Использование

```sh
sh demo/get-demo-games.sh        # скачать 4 свободные GPL-игры на полку
./bt-j2me                        # меню-полка (~/.local/share/bt-j2me/games)
./bt-j2me ~/игры/j2me            # полка из другой папки
./bt-j2me run игра.jar           # запустить игру сразу, без меню
./bt-j2me info игра.jar          # название, MIDlet-ы, проверка всех классов
./bt-j2me display-test           # проверить экран и клавиши
```

Опции: `--windowed` — в окне, `--gpu` — рисовать через OpenGL (по умолчанию
программно: так на порядок меньше памяти и надёжнее на старых ПК),
`--smooth` / `--sharp` — дробный или только целый масштаб игр.

### Интерфейс

Три вкладки внизу (иконки, без подписей):

- **Полка** (геймпад) — коробки игр в 3D: центральная крупная, соседние
  повёрнуты к ней торцом; название и издатель под коробкой, `‹ ›` по бокам,
  счётчик сверху. При запуске из коробки выезжает крутящийся диск.
- **Библиотека** (список) — все игры сеткой, выбор переносит на полку.
- **Настройки** (шестерёнка) — три переключателя: ☀/☾ тема, «шахматка» —
  крупный/мелкий пиксель интерфейса, «лесенка» — только целый масштаб игр.
  Сохраняются в `~/.config/bt-j2me/settings`.

Интерфейс рисуется в маленьком разрешении (короткая сторона ≈190 пикселей,
в режиме мелкого пикселя ≈270) и увеличивается целым множителем — поэтому
он чёткий и занимает весь экран без полей на любом мониторе, ноутбуке,
ЭЛТ или вертикальном экране.

### Обложки

Обложка ищется так:

1. `<папка>/<имя-jar>.png`
2. `<папка>/covers/<имя-jar>.png`
3. иначе рисуется автоматически: цвет по названию, значок-овал и
   крупная иконка игры из JAR (или диск, если иконки нет) — без надписей.

Подойдёт любая PNG; лучше вертикальная примерно 3:4 (как коробка), иначе
лишнее по краям обрезается. Уменьшается с усреднением, поэтому сканы
настоящих обложек тоже смотрятся аккуратно.

### Управление

| Действие               | Клавиатура            | Xbox-геймпад            |
|------------------------|-----------------------|-------------------------|
| Листать / выбирать     | стрелки (WASD, 2468)  | крестовина / левый стик |
| Запустить / включить   | Enter, пробел, 5      | A                       |
| Соседняя вкладка       | * / # (numpad / и *)  | LB / RB                 |
| Перейти к вкладкам     | ↓ на полке            | ↓                       |
| Назад / выход          | Esc                   | кнопка Xbox             |

Мышь тоже работает: клик по коробке, стрелкам, вкладкам, переключателям.

В играх с полями ввода (имя в таблице рекордов) буквы печатаются с
клавиатуры, Backspace стирает.

В игре: стрелки/WASD и крестовина/стик — джойстик телефона; Enter и **A** —
«огонь»; F1/Q и **Start** — левая софт-клавиша; F2/E и **B** — правая софт-клавиша
(«назад»); цифры — цифры, а на геймпаде **X** = 1, **Y** = 3, **LB** = *, **RB** = #,
**View** = 0. Геймпады подключаются на лету — в углу появляется значок.

### Сенсорное управление (Android, на ПК — `--touch`)

Картинка игры в портрете стоит сверху, кнопки — под ней, в альбоме — по бокам:

- слева **плавающий стик**, как L3 у геймпада: он появляется там, куда поставили
  палец, а если увести палец дальше, центр едет следом. Можно выбрать 8 направлений
  или только 4 (так удобнее для старых игр и меню);
- справа квадратная кнопка **огонь** (центр крестовины, «5»), сверху две
  **софт-клавиши**;
- **⌨** выдвигает цифровую панель 1–9, *, 0, #;
- **⚙** открывает редактор. В нём любую клавишу телефона (стрелки, цифры, *, #, C,
  софт-клавиши, стик, панель) можно закрепить кнопкой поверх игры или убрать,
  перетащить пальцем, изменить её размер и общую прозрачность. Раскладка
  запоминается **для каждой игры отдельно**, своя для портрета и альбома.

Касание самой картинки передаётся игре как касание экрана. Нажатия дают короткий
отклик вибрацией, а `Display.vibrate()` из игр включает настоящую вибрацию.

## Java-машина

Своя, на C, без JRE: CLDC 1.1 (`java.lang`, `java.util`, `java.io`) и MIDP 2.0.

| Что | Состояние |
|---|---|
| Байткод | все опкоды Java 1.0–8 (кроме `invokedynamic`), исключения, `synchronized`, `jsr/ret` |
| Потоки | «зелёные» в одном системном потоке: `Thread`, `wait/notify`, `sleep`, `Timer` |
| Память | сборщик mark&sweep, куча до 48 МБ |
| `lcdui` | `Canvas`, `Graphics` (всё рисование, повороты картинок, пропорциональные шрифты с кириллицей), `Image` (PNG), `Form`, `List`, `Alert`, `TextBox`, `TextField`, `ChoiceGroup`, `Gauge`, команды и софт-клавиши с меню |
| `lcdui.game` | `GameCanvas`, `Sprite` (кадры, повороты, столкновения), `TiledLayer`, `LayerManager` |
| `rms` | `RecordStore` с перебором, фильтрами, сортировкой; файлы в `~/.local/share/bt-j2me/rms/<игра>/` |
| Свойства | `getAppProperty` читает JAD рядом с JAR, затем манифест |
| Nokia UI | `FullCanvas`, `DirectUtils`, `DirectGraphics`, `DeviceControl` |
| Звук (MMAPI, Nokia Sound) | заглушки: игры не падают, но молчат |
| Bluetooth (JSR-82), SMS (JSR-120), сеть | заглушки: игра узнаёт «недоступно» и показывает свою ошибку; платные SMS из взломанных сборок не уходят |
| M3G / Mascot Capsule (3D) | нет |

Экран игры — 240×320 или размер из `Nokia-MIDlet-Original-Display-Size`.
Нажатие клавиши доходит до игры не короче 100 мс: многие игры опрашивают
клавиши раз в кадр и иначе не заметили бы быстрый тап.
Если игра не запустилась, лаунчер покажет красный крест, а причину — в терминале;
`BT_J2ME_TRACE=1` печатает каждое брошенное в игре исключение.

Библиотека классов — Java-исходники в `runtime/`; после правок пересоберите её
`tools/build-rt.sh` (нужен JDK), получится новый `src/rt_jar.h`.
