# CRT Overlay

Превращает весь рабочий стол Windows или Linux в изображение настоящего
ЭЛТ-монитора — поверх любых программ, видео и игр в оконном режиме.

Основной шейдер — **CRT Tube**: модель кинескопа, параметры которой подобраны
численно по фотографии реального ЭЛТ-монитора (см. «Как подобран CRT Tube»).
Также встроены пресеты **CRT-Guest-Advanced** (guest(r), из
[libretro/slang-shaders](https://github.com/libretro/slang-shaders)).

Работает тихо: окна и пункта на панели задач нет, клики проходят сквозь оверлей.
Управляется **только из иконки в трее** — там же оверлей выключается и
закрывается.

## Как это работает

1. Поверх выбранного монитора создаётся окно без рамки, всегда сверху,
   не принимающее мышь и фокус.
2. Каждый кадр захватывается изображение рабочего стола **под** этим окном:
   - **Windows** — окно помечено `WDA_EXCLUDEFROMCAPTURE`, поэтому само в
     захват не попадает. Способ захвата выбирается автоматически:
     Windows.Graphics.Capture (работает и на ноутбуках с двумя видеокартами),
     если недоступен — DXGI Desktop Duplication, в крайнем случае — GDI BitBlt.
   - **Linux (X11)** — расширение XComposite: каждое окно читается из своего
     внеэкранного буфера (MIT-SHM) и собирается в текстуру снизу вверх, без
     окна оверлея. Окна, полностью закрытые непрозрачными окнами сверху,
     не читаются.
3. Картинка уменьшается до «ЭЛТ-разрешения» — числа строк развёртки
   (пункт **Строк развёртки**, по умолчанию 240 на 1080p) — и проходит через
   шейдер в формате RetroArch `.slangp`
   ([librashader](https://github.com/SnowflakePowered/librashader), OpenGL 3.3).
   Каждая строка картинки рисуется как строка развёртки кинескопа.
4. Результат выводится в окно оверлея.

## Требования

| | Windows | Linux |
|---|---|---|
| ОС | Windows 10 версии 2004 (май 2020) или новее, Windows 11 | сеанс **X11** (Xorg) |
| Графика | OpenGL 3.3; на старых видеокартах — OpenGL 2.1 (облегчённый режим) | то же |
| Трей | стандартный | любой трей с поддержкой StatusNotifierItem (KDE, XFCE, Cinnamon, MATE, LXQt…). В GNOME нужно расширение «AppIndicator and KStatusNotifierItem Support» |

**Старые компьютеры.** Если OpenGL 3.3 нет (Intel GMA 4500/X4500, GMA 3150,
старые Radeon и GeForce), программа сама переключается на облегчённый рендер
на OpenGL 2.1: тот же вид CRT Tube, около 14 выборок текстуры на пиксель
вместо 40 и 30 кадров/с по умолчанию. Включить его вручную:
`renderer = "lite"` в `config.toml`. В облегчённом режиме работает только
CRT Tube (пресеты guest-advanced требуют OpenGL 3.3). Linux-сборка из
релизов собрана под glibc 2.31 и запускается на Debian 11+/Devuan 4+
(в том числе Daedalus), Ubuntu 20.04+.

Чистый Wayland не поддерживается: там программам нельзя ни снимать экран
без запроса, ни держать окно поверх всех. Под XWayland захватятся только
X11-окна.

## Установка одной командой

Linux (x86_64, X11):

```bash
curl -fsSL https://raw.githubusercontent.com/FLEXIY0/BT-J2ME/refs/heads/claude/amazing-fermi-l6s51a/crt-overlay/install.sh | sh
```

Без автозапуска: `curl -fsSL …/install.sh | sh -s -- --no-autostart`,
удаление: `curl -fsSL …/install.sh | sh -s -- --uninstall`.
Программа ставится в `~/.local/bin`, без root.

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/FLEXIY0/BT-J2ME/refs/heads/claude/amazing-fermi-l6s51a/crt-overlay/install.ps1 | iex
```

Ставится в `%LOCALAPPDATA%\crt-overlay`, ярлыки — в меню «Пуск» и в автозагрузку.

## Запуск

Windows SmartScreen может предупредить о неподписанной программе:
«Подробнее» → «Выполнить в любом случае». Окна у программы нет — после
запуска появляется иконка в трее (возможно, под стрелкой ^) и шейдер на
экране. Повторный запуск только сообщит, что программа уже работает.

Скачайте архив для своей ОС со страницы *Releases* (или из артефактов
GitHub Actions) и запустите `crt-overlay` / `crt-overlay.exe`. Шейдеры
встроены в программу, ничего дополнительно ставить не нужно.

Меню в трее:

- **Нагрузка** — частота кадров, время GPU на кадр, время захвата экрана и
  загрузка процессора программой (обновляется раз в секунду; то же раз в
  10 секунд пишется в журнал);
- **Шейдер включён** — включить/выключить оверлей (программа остаётся в трее);
- **Режим / пресет** — CRT Tube или варианты CRT-Guest-Advanced;
- **Строк развёртки** — сколько строк кинескопа на высоту экрана: *Авто*
  (240 на 1080p, 320 на 1440p, 480 на 4K) или 180…480. Меньше строк —
  крупнее «пиксели» и сильнее эффект;
- **Монитор** — на каком мониторе работать;
- **Перезагрузить шейдер и настройки** — перечитать `config.toml`;
- **Открыть файл настроек** — открыть `config.toml` в редакторе;
- **Выход** — единственный способ закрыть программу.

Для автозапуска положите ярлык в `shell:startup` (Windows) или `.desktop`-файл
в `~/.config/autostart/` (Linux).

## Настройки

Файл `config.toml` создаётся при первом запуске:

- Windows: `%APPDATA%\crt-overlay\config.toml`
- Linux: `~/.config/crt-overlay/config.toml`

```toml
preset = "crt-tube"   # crt-tube, crt-guest-advanced(-fast/-fastest/-hd/-ntsc/-pal) или путь к .slangp
monitor = 0           # 0 = основной монитор, 1..N — номер из меню
lines = 0             # строк развёртки, 0 = авто
max_fps = 0           # 0 = по вертикальной синхронизации монитора
enabled = true

[params]              # любые параметры шейдера (#pragma parameter)
# TUBE_MASK_STR = 0.3     # сила апертурной решётки
# TUBE_GLOW = 0.2         # свечение
# TUBE_CONV_R = 0.1       # расхождение лучей красного/синего
```

В `preset` можно указать путь к любому другому шейдеру RetroArch в формате
`.slangp` — например, из полной коллекции slang-shaders.

Можно запустить с другим файлом настроек: `crt-overlay --config путь/к/config.toml`.
Журнал пишется в `%LOCALAPPDATA%\crt-overlay\crt-overlay.log` /
`~/.cache/crt-overlay/crt-overlay.log` (при запуске из терминала — в консоль;
подробнее: `RUST_LOG=debug`).

## Как подобран CRT Tube

За эталон взята пара картинок «Original / CRT Monitor» (один и тот же кадр
из игры, справа — снимок реального ЭЛТ). Из левой половины восстановлен арт в
родном разрешении (49×69 пикселей), измерены шаг строк (6,0 точки — одна
строка на строку арта), шаг маски (вертикальные полосы, 3,66 точки) и
расхождение лучей. Затем численная модель кинескопа — горизонтальный
гауссов луч, строки, ширина которых растёт с яркостью, апертурная решётка,
сведение красного/синего, свечение, гамма и насыщенность — подогнана
оптимизатором под правую половину. Шейдер `shaders/shaders/tube/crt-tube.slang`
повторяет эту модель формула в формулу; рендер одного кадра через программу
совпадает с моделью до долей процента.

Проверить самому: `crt-overlay --render-still арт.png результат.png ширина высота`
прогоняет картинку (одна строка = одна строка развёртки) через тот же OpenGL-путь,
что и оверлей. Опции: `--preset`, `--config`, `--frames`.

## Память и нагрузка

CRT Tube (по умолчанию) рисуется собственным рендером программы, без
librashader: сама программа занимает около 14 МБ, плюс 8 МБ буфер захвата
экрана, плюс память графического драйвера (обычно десятки МБ; на машинах без
видеокарты, где Mesa рисует программно через LLVM, — около 120 МБ).
Пресеты guest-advanced загружают librashader с компиляторами шейдеров и
12 проходами — они тяжелее примерно на 60–100 МБ.

Текущие кадры/с, время GPU, захвата и загрузку CPU показывает строка
«Нагрузка» в меню трея.

## Ограничения

- Курсор мыши рисует система поверх оверлея, он остаётся без шейдера. Если
  включить кривизну (`warpX`/`warpY`), изображение под курсором немного
  сместится относительно реального положения клика.
- Игры в **эксклюзивном** полноэкранном режиме не захватываются — используйте
  оконный или «полноэкранный в окне» режим.
- Защищённое DRM-видео (Netflix и т. п. в браузере) на Windows в захвате
  выглядит чёрным.
- На Windows при HDR рабочий стол захватывается в SDR.
- Задержка — примерно один кадр.
- Linux: окно оверлея обходит оконный менеджер (override-redirect) и само
  поднимается наверх, если его перекрыли.

## Сборка из исходников

Нужен [Rust](https://rustup.rs) (1.87+) и компилятор C++ (librashader собирает
glslang и SPIRV-Cross).

```bash
cargo build --release
```

Сборка, совместимая со старым glibc (нужны `pip install ziglang` и
`cargo install cargo-zigbuild`):

```bash
cargo zigbuild --release --target x86_64-unknown-linux-gnu.2.31
```

Результат: `target/release/crt-overlay` (`.exe` на Windows). На Linux
дополнительные dev-пакеты не нужны: X11, GL и D-Bus подгружаются во время
работы. Собрать Windows-версию из Linux можно через MinGW:

```bash
rustup target add x86_64-pc-windows-gnu
```

```bash
cargo build --release --target x86_64-pc-windows-gnu
```

## Структура

```
src/main.rs             цикл событий, окно, OpenGL-контекст, команды трея
src/tray.rs             иконка и меню трея
src/render.rs           уменьшение картинки → цепочка librashader → окно, таймер GPU
src/stats.rs            замер нагрузки (кадры, GPU, захват, CPU)
src/still.rs            --render-still: рендер одного кадра в файл
src/lite.rs             облегчённый рендер CRT Tube для OpenGL 2.1
src/gfx.rs              выбор рендера (полный / облегчённый)
src/capture/windows.rs  захват: Windows.Graphics.Capture / DXGI / GDI
src/capture/x11.rs      захват через XComposite + MIT-SHM
src/config.rs           config.toml (комментарии сохраняются при записи)
src/shaders.rs          встроенные пресеты, распаковка в кэш
shaders/                CRT Tube и CRT-Guest-Advanced (libretro/slang-shaders)
```
